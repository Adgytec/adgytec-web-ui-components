# Gradients Utility

The gradients utility provides a set of constants representing the available premium, subtle gradient variants in the design system. These constants map to CSS class names designed specifically for cards to provide visual depth without affecting text readability or distracting the user.

## Constants

### `gradientStyles`

A curated set of subtle card background gradients that automatically adapt to light and dark theme modes using Material You CSS Custom Properties.

| Category | Variant | Description / Style Direction |
|:---|:---|:---|
| **Ambient** | `AmbientPrimary` | Soft, diagonal Primary (`10%`) to Secondary (`7%`) blend |
| | `AmbientSecondary` | Soft, diagonal Secondary (`10%`) to Tertiary (`7%`) blend |
| | `AmbientTertiary` | Soft, diagonal Tertiary (`10%`) to Primary-Alt (`7%`) blend |
| | `AmbientAlt` | Soft, diagonal Primary-Alt (`10%`) to Primary (`7%`) blend |
| **Top Glow** | `GlowPrimary` | Concentrates a Primary (`12%` to `3%`) vertical glow at the top |
| | `GlowSecondary` | Concentrates a Secondary (`12%` to `3%`) vertical glow at the top |
| | `GlowTertiary` | Concentrates a Tertiary (`12%` to `3%`) vertical glow at the top |
| | `GlowAlt` | Concentrates a Primary-Alt (`12%` to `3%`) vertical glow at the top |
| **Corner Radial** | `CornerPrimary` | Top-left Primary (`11%`) & bottom-right Secondary (`8%`) radial glow |
| | `CornerSecondary` | Top-left Secondary (`11%`) & bottom-right Tertiary (`8%`) radial glow |
| | `CornerTertiary` | Top-left Tertiary (`11%`) & bottom-right Primary-Alt (`8%`) radial glow |
| | `CornerAlt` | Top-left Primary-Alt (`11%`) & bottom-right Primary (`8%`) radial glow |
| **Monochromatic** | `LusterSoft` | Subtle top-to-bottom surface container gradient |
| | `LusterMetallic` | Sleek diagonal surface container metallic-like gradient |
| | `LusterDeep` | Deeper monochromatic gradient (high to lowest container levels) |

*Note: All gradients include standard text color properties (e.g., `color: var(--md-sys-color-on-surface)`) and background color fallbacks to maintain contrast and readability.*

## Usage

```tsx
import { gradientStyles } from '@adgytec/web-ui-components';
import clsx from 'clsx';

function CardComponent() {
  return (
    <div className={clsx('card-base', gradientStyles.AmbientPrimary)}>
      <h3>Card Title</h3>
      <p>This card background uses a soft, ambient primary-to-secondary gradient.</p>
    </div>
  );
}

function GlowCardComponent() {
  return (
    <div className={clsx('card-base', gradientStyles.GlowSecondary)}>
      <h3>Backlit Header</h3>
      <p>This card features a subtle backlit accent color along the top edge.</p>
    </div>
  );
}
```
