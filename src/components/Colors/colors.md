# Colors

The `Colors` module contains color presentation and manipulation components adhering to Material Design 3 and built on top of [React Aria Components](https://react-spectrum.adobe.com/react-aria/).

## Components

- [ColorSwatch](./ColorSwatch/ColorSwatch/color-swatch.md): A visual preview swatch displaying single color values or color channels with Material 3 shape and sizing presets.
- [ColorSwatchPicker](./ColorSwatch/ColorSwatchPicker/color-swatch-picker.md): An accessible palette selector allowing users to choose from a list of color swatches with grid/stack layouts and synchronized shape/size context.
