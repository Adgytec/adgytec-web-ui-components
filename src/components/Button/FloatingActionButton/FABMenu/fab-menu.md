# FAB Menu (Speed Dial)

The `FABMenu` system implements the [Material 3 Speed Dial](https://m3.material.io/components/floating-action-button/overview) pattern. When tapped, a FAB menu expands into a stack of related actions, displaying small pill-shaped action buttons above the main floating action button.

## Configurable CSS Tokens

The `FABMenu` components inherit the standard FAB configurable tokens for background and icon/text colors:

| Token                 | Description                                               |
| --------------------- | --------------------------------------------------------- |
| `--md-fab-background` | Background color of the floating action button container. |
| `--md-fab-color`      | Text and icon color of the floating action button.        |

## Components

The `FABMenu` system is composed of:

- `FABMenuTrigger`: The top-level state controller (based on React Aria Components `MenuTrigger`) that provides the semantic `variant` context to descendant components.
- `FABMenuButton`: The primary trigger button that morphs into a circular container with an `X` (close) icon when pressed.
- `FABMenuPopover`: A specialized popover surface configured with `placement="top end"`, `shouldFlip={false}`, and two-dimensional scale entrance/exit animations (`data-scale-xy`).
- `FABMenu`: The menu container (extending React Aria Components `Menu`) that arranges items in a vertical column aligned to the trailing edge.
- `FABMenuItem`: Action item (extending React Aria Components `MenuItem`) rendered as a small, pill-shaped Extended FAB with an icon and label.

## Props

### `FABMenuTrigger`

Extends [React Aria Components MenuTrigger](https://react-spectrum.adobe.com/react-aria/Menu.html#menutrigger).

| Prop      | Type                                     | Default     | Description                                                              |
| --------- | ---------------------------------------- | ----------- | ------------------------------------------------------------------------ |
| `variant` | `"primary" \| "secondary" \| "tertiary"` | `"primary"` | Semantic palette mapping to system colors inherited by descendant items. |

### `FABMenuButton`

Extends [FloatingActionButton](src/components/Button/FloatingActionButton/FloatingActionButton/types.ts) (excluding `color` and `variant`).

| Prop      | Type                             | Default      | Description                                        |
| --------- | -------------------------------- | ------------ | -------------------------------------------------- |
| `icon`    | `LucideIcon`                     | **Required** | The primary icon to display inside the FAB.        |
| `size`    | `"small" \| "medium" \| "large"` | `"medium"`   | Size preset of the trigger button container.       |
| `tooltip` | `string`                         | —            | Optional tooltip text displayed on hover or focus. |

### `FABMenuPopover`

Extends [Popover](src/components/Popover/Popover.tsx) (excluding `placement` and `shouldFlip`).

### `FABMenu`

Extends [React Aria Components Menu](https://react-spectrum.adobe.com/react-aria/Menu.html).

### `FABMenuItem`

Extends [React Aria Components MenuItem](https://react-spectrum.adobe.com/react-aria/Menu.html#menuitem).

| Prop   | Type         | Default      | Description                                       |
| ------ | ------------ | ------------ | ------------------------------------------------- |
| `icon` | `LucideIcon` | **Required** | Lucide icon displayed alongside the action label. |

## Usage

```tsx
import {
    FABMenu,
    FABMenuButton,
    FABMenuItem,
    FABMenuPopover,
    FABMenuTrigger,
} from "@adgytec/web-ui-components";
import { Camera, FileText, Plus, Upload } from "lucide-react";

<FABMenuTrigger variant="primary">
    <FABMenuButton
        icon={Plus}
        tooltip="Quick actions"
        aria-label="Quick actions"
    />

    <FABMenuPopover>
        <FABMenu onAction={(key) => console.log(key)}>
            <FABMenuItem id="document" icon={FileText}>
                Document
            </FABMenuItem>
            <FABMenuItem id="photo" icon={Camera}>
                Take Photo
            </FABMenuItem>
            <FABMenuItem id="upload" icon={Upload}>
                Upload File
            </FABMenuItem>
        </FABMenu>
    </FABMenuPopover>
</FABMenuTrigger>;
```
