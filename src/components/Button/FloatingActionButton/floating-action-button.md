# Floating Action Button

## Configurable CSS Tokens

| Token                 | Description                                               |
| --------------------- | --------------------------------------------------------- |
| `--md-fab-background` | Background color of the floating action button container. |
| `--md-fab-color`      | Text and icon color of the floating action button.        |

Floating Action Buttons (FABs) are implementations of [Material 3 Floating Action Buttons](https://m3.material.io/components/floating-action-button/overview). A FAB represents the primary action on a screen, appearing in front of all other content to encourage key user activities.

## Components

The FAB system includes:

- `FloatingActionButton`: Standard icon-only FAB with rounded/squircle container.
- `ExtendedFloatingActionButton`: Extended FAB with an icon and text label (or text only), providing additional context for the action.
- `FABMenu`: An expandable Speed Dial menu system. See [FAB Menu documentation](src/components/Button/FloatingActionButton/FABMenu/fab-menu.md).

## Props

### `FloatingActionButton`

Extends [React Aria Components Button](https://react-spectrum.adobe.com/react-aria/Button.html) (excluding `children`).

| Prop      | Type                                     | Default      | Description                                        |
| --------- | ---------------------------------------- | ------------ | -------------------------------------------------- |
| `icon`    | `LucideIcon`                             | **Required** | The icon to display inside the FAB.                |
| `color`   | `"filled" \| "tonal"`                    | `"filled"`   | Visual color scheme of the container.              |
| `variant` | `"primary" \| "secondary" \| "tertiary"` | `"primary"`  | Semantic palette mapping to system colors.         |
| `size`    | `"small" \| "medium" \| "large"`         | `"medium"`   | Size preset of the FAB container and icon.         |
| `tooltip` | `string`                                 | —            | Optional tooltip text displayed on hover or focus. |

### `ExtendedFloatingActionButton`

Extends [React Aria Components Button](https://react-spectrum.adobe.com/react-aria/Button.html).

| Prop            | Type                                     | Default     | Description                                         |
| --------------- | ---------------------------------------- | ----------- | --------------------------------------------------- |
| `children`      | `ReactNode`                              | —           | Label text or content displayed inside the button.  |
| `icon`          | `LucideIcon`                             | —           | Optional icon displayed alongside the label.        |
| `iconPlacement` | `"start" \| "end"`                       | `"start"`   | Position of the icon relative to the label text.    |
| `color`         | `"filled" \| "tonal"`                    | `"filled"`  | Visual color scheme of the container.               |
| `variant`       | `"primary" \| "secondary" \| "tertiary"` | `"primary"` | Semantic palette mapping to system colors.          |
| `size`          | `"small" \| "medium" \| "large"`         | `"medium"`  | Size preset of the container, icon, and typography. |
| `tooltip`       | `string`                                 | —           | Optional tooltip text displayed on hover or focus.  |

## Usage

### Floating Action Button

```tsx
import { FloatingActionButton } from "@adgytec/web-ui-components";
import { Plus } from "lucide-react";

// Standard FAB
<FloatingActionButton
    icon={Plus}
    tooltip="Add item"
    aria-label="Add item"
    onPress={() => console.log("Added")}
/>

// Tonal secondary large FAB
<FloatingActionButton
    icon={Plus}
    color="tonal"
    variant="secondary"
    size="large"
    aria-label="Add item"
/>
```

### Extended Floating Action Button

```tsx
import { ExtendedFloatingActionButton } from "@adgytec/web-ui-components";
import { Navigation, Pencil } from "lucide-react";

// Extended FAB with leading icon
<ExtendedFloatingActionButton
    icon={Pencil}
    onPress={() => console.log("Compose")}
>
    Compose
</ExtendedFloatingActionButton>

// Extended FAB with trailing icon and tonal tertiary color
<ExtendedFloatingActionButton
    icon={Navigation}
    iconPlacement="end"
    color="tonal"
    variant="tertiary"
>
    Navigate
</ExtendedFloatingActionButton>

// Extended FAB without icon
<ExtendedFloatingActionButton>
    Explore
</ExtendedFloatingActionButton>
```
