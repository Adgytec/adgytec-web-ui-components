# Shape

## Configurable CSS Tokens

| Token              | Default Value  | Description                                 |
| ------------------ | -------------- | ------------------------------------------- |
| `--md-shape-color` | `currentColor` | Background fill color of the shape element. |

The `Shape` component renders elements styled and masked with [Material Design 3 Expressive Shapes](https://m3.material.io/styles/shape/overview). Sourced from the [Beer CSS Shapes](https://github.com/beercss/beercss/blob/main/docs/SHAPE.md) specification, it uses CSS `mask-image` to clip its background and children into any of the 35 distinct expressive shapes.

## Sizing

The `Shape` component does not set any fixed width or height dimensions. It enforces a square `aspect-ratio: 1 / 1`, allowing the container size to be driven naturally by the size of its children or external dimensions.

## Props

The `Shape` component extends standard `<div>` HTML attributes (`React.ComponentPropsWithRef<"div">`).

| Prop   | Type        | Default      | Description                                                          |
| ------ | ----------- | ------------ | -------------------------------------------------------------------- |
| `name` | `ShapeName` | **Required** | The Material 3 expressive shape to display (union of all 35 shapes). |

## Available Shapes

The `name` prop accepts any of the 35 Material 3 expressive shape names:

| Category             | Shapes                                                                                                          |
| -------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Geometric**        | `arch`, `arrow`, `circle`, `diamond`, `oval`, `pentagon`, `pill`, `semicircle`, `slanted`, `square`, `triangle` |
| **Organic & Nature** | `bun`, `clamshell`, `fan`, `flower`, `gem`, `heart`, `leaf-clover4`, `leaf-clover8`, `puffy`, `puffy-diamond`   |
| **Bursts & Stars**   | `boom`, `burst`, `soft-boom`, `soft-burst`, `sunny`, `very-sunny`                                               |
| **Cookies**          | `sided-cookie4`, `sided-cookie6`, `sided-cookie7`, `sided-cookie9`, `sided-cookie12`                            |
| **Playful & Pixel**  | `ghost-ish`, `pixel-circle`, `pixel-triangle`                                                                   |

All shape names are also exported as the constant array [`ShapeNames`](file:///home/rohan/work/adgytec/adgytec-web-ui-components/src/components/Shape/types.ts#L4-L40).

## Usage

### Shape Sized by Children

```tsx
import { Shape } from "@adgytec/web-ui-components";

// Sized by a child element with currentColor
<div style={{ color: "var(--md-sys-color-primary)" }}>
    <Shape name="heart">
        <div style={{ width: 48, height: 48 }} />
    </Shape>
</div>

// Sized by child image
<Shape name="flower">
    <img
        src="avatar.jpg"
        alt="Avatar"
        style={{ width: 120, height: 120, objectFit: "cover" }}
    />
</Shape>
```

### Customizing Color

```css
.custom-shape {
    --md-shape-color: var(--md-sys-color-primary);
}
```

```tsx
<Shape name="leaf-clover4" className="custom-shape">
    <div style={{ width: 64, height: 64 }} />
</Shape>;
```
