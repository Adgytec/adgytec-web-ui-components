# LoadingIndicator

## Configurable CSS Tokens

| Token                                           | Default Value                                                                                  | Description                                                       |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `--md-loading-indicator-active-indicator-color` | Variant-dependent (`var(--md-sys-color-primary)` / `var(--md-sys-color-on-primary-container)`) | The color of the active animated loading indicator shape.         |
| `--md-loading-indicator-container-color`        | Variant-dependent (`transparent` / `var(--md-sys-color-primary-container)`)                    | The background color of the circular loading indicator container. |

The `LoadingIndicator` component represents an indeterminate loading state, displaying a continuous shape-morphing animation inspired by [Material 3 Progress Indicators](https://m3.material.io/components/progress-indicators/overview) and [Beer CSS Shapes](https://github.com/beercss/beercss/blob/main/docs/SHAPE.md). It uses an SVG mask with rotation and path morphing to indicate ongoing processes or background activity.

## Props

| Prop          | Type                       | Default     | Description                                                                                                                                          |
| ------------- | -------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `containment` | `"default" \| "contained"` | `"default"` | Visual containment style of the indicator. `"default"` has a transparent background, while `"contained"` renders inside a filled circular container. |
| `size`        | `number`                   | `48`        | The container size in pixels (dp). Clamped between `24` (`MinLoadingIndicatorSize`) and `240` (`MaxLoadingIndicatorSize`).                           |

## Containment Variants

1. **Default (`"default"`)**:
   - Transparent container background.
   - Indicator uses `--md-sys-color-primary` by default.
2. **Contained (`"contained"`)**:
   - Container has a circular filled background (`--md-sys-color-primary-container` by default).
   - Indicator uses `--md-sys-color-on-primary-container` by default.

## Sizing

The indicator container size is controlled via the `size` prop:
- Minimum size: `24px` (`MinLoadingIndicatorSize`)
- Default size: `48px` (`DefaultLoadingIndicatorSize`)
- Maximum size: `240px` (`MaxLoadingIndicatorSize`)

The active indicator shape dynamically scales to `19 / 24` (~79.17%) of the container size to maintain proportional padding and margins across all sizes.

## Usage

```tsx
import { LoadingIndicator } from "@adgytec/web-ui-components";

// Default loading indicator (48px, uncontained)
<LoadingIndicator />

// Contained loading indicator
<LoadingIndicator containment="contained" />

// Custom size (e.g. 32px or 64px)
<LoadingIndicator size={32} />
<LoadingIndicator size={64} containment="contained" />
```

## Customizing Colors

You can override indicator and container colors using CSS custom properties:

```css
/* Custom color theme for loading indicator */
.custom-loading-indicator {
    --md-loading-indicator-active-indicator-color: var(--md-sys-color-tertiary);
    --md-loading-indicator-container-color: var(
        --md-sys-color-tertiary-container
    );
}
```

```tsx
<div className="custom-loading-indicator">
    <LoadingIndicator containment="contained" />
</div>;
```
