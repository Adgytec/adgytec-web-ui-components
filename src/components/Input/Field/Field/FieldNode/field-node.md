# Field Node

The `FieldNode` component is a layout container used to embed custom non-button elements—such as `ColorSwatch`, custom status indicators, avatars, or badges—inside a `Field` as leading or trailing content.

It provides a fixed block size (40px) matching `FieldButton` and centers its content via inline flexbox, ensuring consistent alignment and field container padding.

## Props

Extends standard HTML `<span>` attributes (`React.ComponentPropsWithRef<"span">`).

| Prop       | Type        | Default | Description                                             |
| ---------- | ----------- | ------- | ------------------------------------------------------- |
| `children` | `ReactNode` | —       | Custom element or node to render inside the field slot. |

## Usage

### With ColorSwatch in ColorField

```tsx
import { ColorField, ColorSwatch, FieldNode } from "@adgytec/web-ui-components";

<ColorField
    label="Theme Color"
    defaultValue="#6750a4"
    leading={
        <FieldNode>
            <ColorSwatch size="small" shape="square" />
        </FieldNode>
    }
/>;
```

### Custom Status Indicator in TextField

```tsx
import { FieldNode, TextField } from "@adgytec/web-ui-components";

<TextField
    label="Server Status"
    defaultValue="Online"
    leading={
        <FieldNode>
            <span
                style={{
                    width: 10,
                    height: 10,
                    borderRadius: "50%",
                    backgroundColor: "green",
                }}
            />
        </FieldNode>
    }
/>;
```
